# 🍞 Tost Makinesi Evren Simülasyonu

> *"Evren yanıyor. Ama güzel yanıyor."*  
> — Tost Makinesi, 2026

## 📜 Proje Hakkında

Bu repository, insanlık tarihinin en ciddi ve en saçma bilimsel çalışmasını barındırır.  
**Tost Makinesi Evren Teorisi**'ne göre, içinde yaşadığımız evren aslında dev bir tost makinesinin içinde sıkışmış bir ekmek dilimidir. Karanlık madde unutulmuş reçel, karadelikler yanık noktalar, Big Bang ise sadece "aç" düğmesine basılmasıdır.

Bu simülasyon, teoriyi **gerçekten çalışan** bir Python koduyla kanıtlamaya (ya da en azından eğlendirmeye) çalışır. Kod, yavaş yavaş yazar, rastgele tost seviyeleri hesaplar ve size felsefi sonuçlar sunar. Çünkü hayat da öyle değil mi? Yavaş, rastgele ve biraz yanık.

## 🚀 Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/tost-makinesi-evren-simulasyonu.git
cd tost-makinesi-evren-simulasyonu
python3 simülasyon.py
```

Programı çalıştırın. Ekmeğinizi hazırlayın. Çayınızı demleyin. Sonucu bekleyin. (Sonuç her zaman "yanarsın" değildir, ama genellikle öyledir.)

## 📊 Özellikler

- Yavaş yazma efekti (tost pişirme simülasyonu)
- Rastgele tost seviyesi hesaplama
- Felsefi saçmalıklar üretme
- Klavye kesintisine karşı dayanıklılık (ekmek kurtarma)
- Tamamen Türkçe, çünkü evren de Türkçe konuşur (iddia)

## ⚠️ Uyarılar

- Bu program gerçek bir bilimsel kanıt **değildir**.
- Çalıştırdıktan sonra tost yeme isteği artabilir.
- Simülasyon sırasında "neden buradayım?" sorusu sorulabilir. Cevap: Tost için.
